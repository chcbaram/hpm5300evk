## 1 / 3 — 전원 분배 (USB 5V → 3.3V, 아날로그/디지털 분리)

![전원 분배](sch/sch-1-power.svg)

**요점**

- LDO 2개(U2 아날로그 / U3 디지털)로 나눈다. **스위칭 레귤레이터는 쓰지 않는다** — 12bit ADC 보드에
  1~2MHz 스위칭 노이즈를 들이지 않는 쪽이 이득이고, 총 손실 0.6W는 SOT-223 2개로 감당된다.
- **VREFH와 센서 96개는 R6 뒤의 같은 노드**(VREF_3V3)에서 딴다. 비율계측의 전제다.
- VANA만 페라이트 비드(FB1)로 분리한다. VREFH에는 절대 넣지 않는다.

## 2 / 3 — 코어 전원 (**외부 LDO / 내장 DCDC 미사용**)

> ⚠ **도면 SVG 재작성 필요** — `sch/sch-2-core.svg` 는 아직 내장 DCDC 판이다.

```
+3V3D ──[U4 AMS1117-1.2 SOT-223]──┬── VDD_SOC (1.2V)  U1: 7,17,20,44,57,69,83,94
                                  └── C1,C2,C3 (0603 22uF x3)

내장 DCDC 미사용 — UM 8.2.1 권장에 따라 3핀을 10k 로 접지:
   DCDC_IN  (30) ──[R7 10k]── GND
   DCDC_LP  (29) ──[R8 10k]── GND
   DCDC_SNS (21) ──[R9 10k]── GND
   DCDC_GND (28) ──────────── GND
   L1 4.7uH  →  삭제
```

**요점**

- **2 층 PCB 결정에 따라 코어를 외부 LDO 로 바꿨다.** 전용 GND 플레인이 없는 2 층에서
  DCDC 스위칭 리턴과 96 채널 아날로그 리턴이 포어를 공유하면 공유 임피던스로
  최대 6.5 LSB 잡음이 실릴 수 있다. **스위처를 아예 두지 않아 이 변수를 제거한다.**
- **미사용 DCDC 핀 처리는 벤더 정식 권장이다.** UM 8.2.1:
  *"当用户选择使用外部的电源替代片上的 DCDC 为系统电源域供电时, 建议把 DCDC 的相关引脚
  DCDC_IN、DCDC_LP 和 DCDC_SNS 通过 10k 欧姆电阻接地."*
- **VDD_SOC = 1.2V, CPU 400MHz (균형모드).** 데이터시트 표9 는 동작 모드별로 전압을 나눈다 —
  성능 480MHz: `1.25/1.275/1.30V`, **균형 400MHz: `1.15/1.175/1.30V`**, 절전 280MHz: `1.05/1.075/1.30V`.
  **1.2V 는 균형모드 범위 안**이며 전형값 1.175V 에 가깝다.
  480MHz 를 쓰려면 1.275V 가 필요한데 고정 LDO 로는 창(1.25~1.30V)을 맞추기 어렵다
  (1.25V 품은 ±2% 에서 최소값 미달, 1.30V 품은 최대값 초과). **400MHz 로 간다.**
  CPU 예산은 15.3 → 18.4us 로 늘지만 총 63.5us / 125us = **51%** 라 여유가 충분하다.
- **C1 = 33~66uF 규격 유지.** 0603 22uF 6.3V 3 개 (최악 유효용량 38uF).
  AMS1117 이 요구하는 최소 22uF 도 동시에 만족한다.
- VDD_PMCCAP(33) / VDD_OTPCAP(23)은 **내부 LDO 출력**이다. 3.3V를 물리면 안 된다.
  이 둘은 VPMC 를 입력으로 쓰므로 DCDC 미사용과 무관하게 그대로 유지한다.

## 3 / 3 — 클럭 · 리셋 · 부트 · VBUS 감지

![클럭/리셋/부트](sch/sch-3-clock.svg)

**요점**

- **LQFP100은 내부 RC 부팅을 지원하지 않는다**(표44). 크리스털이 죽으면 칩이 뜨지 않는다.
- **BOOT0(PA02) 버튼 또는 패드는 필수.** LQFP100만 USB0 ISP가 되므로 디버거 없는 복구 경로다.
- RESET_N은 저레벨 300us 이상 필요(표12) → 10k x 100nF = 1ms.

## 6. 실장 확인 체크리스트

1. VDD_SOC 8핀 **전부** 연결 (7, 17, 20, 44, 57, 69, 83, 94) — **U4 출력에서**
2. VSS 12핀 **전부** 연결
3. **DCDC_IN(30) / DCDC_LP(29) / DCDC_SNS(21)를 각각 10k 로 접지**했는가 (UM 8.2.1). **L1 은 없다**
4. VDD_PMCCAP(33) / VDD_OTPCAP(23)에 **3.3V를 물리지 않았는가**
5. VPMC(31)가 +3V3D에서 직접 오는가 (별도 스위치/LDO 금지 — 상하전 순서)
6. VREFH(65)와 센서 VCC가 **같은 노드**인가
7. VREFL(64)이 GND인가
8. BOOT0 진입 수단(SW2)이 있는가
9. 크리스털 배선 5mm 이내, 하부 통 GND
10. LDO 3 개(U2/U3/U4)의 **TAB 이 각자 VOUT 네트**에 붙어 있고 **방열 동박이 645mm² 이상**인가
    (서멀 비아 4~8 개, 드릴 0.3mm, 피치 1.0~1.2mm)
11. **U4 출력이 1.2V** 이고 **펌웨어가 CPU 를 400MHz(균형모드)로 설정**하는가 —
    표9 상 480MHz 는 최소 1.25V 를 요구하므로 1.2V 에서 480MHz 를 쓰면 스펙 위반이다
12. **디버그 커넥터 J2 의 1 번(VTref)이 +3V3D, 10 번(nRESET)이 RESET_N** 에 연결됐는가
13. JTAG 풀 저항: TMS/TDI 풀업, TCK 풀다운, **PA08(TRST) 풀업**
14. **2 층 레이아웃** — GND 단일 포어(컷 없음), MUX 12 개를 하면 센서 근처에 배치
